RECEIPT SCANNING

Scan a receipt. Review before you save.

ShareSquad can read merchant name, date, and total from a receipt photo. Suggestions are never saved as an expense until you confirm or correct them.

Local reading first

Every scan starts with free, on-server receipt reading. For many clear printed receipts, that is enough—no AI key required.

Optional Google AI Studio help

If a receipt is unclear, you can connect your own Google AI Studio API key for Gemini-powered extraction:

  1. Open Settings → Receipt scanning.
  2. Turn on Use my own AI API key.
  3. Select Google and a Gemini model.
  4. Create an API key in Google AI Studio, paste it into ShareSquad, and save.

Your API key is encrypted at rest and is not shown again after you save it. Google controls its own free-tier availability and limits.

You stay in control

Whether the details came from local OCR or Gemini, check store name, date, amount, and category before saving. A receipt is optional—you can always enter an expense manually.
