RECEIPT SCANNING

Scan a receipt. Review before you save.

ShareSquad can read merchant name, date, and total from a receipt photo. Suggestions are never saved as an expense until you confirm or correct them.

Local reading first

Every scan starts with free, on-server receipt reading. It cleans uneven lighting and crease shadows, corrects perspective where possible, and uses layout-aware total matching. For many printed receipts, that is enough—no AI key required.

Optional provider help

If a receipt is unclear, you can connect your own supported vision-provider API key:

  1. Open Settings → Receipt scanning.
  2. Turn on Use my own AI API key.
  3. Select a provider and model.
  4. Create an API key with that provider, paste it into ShareSquad, and save.

Your API key is encrypted at rest and is not shown again after you save it. Your chosen provider controls its own pricing, free tier, and limits.

You stay in control

Whether the details came from local OCR or an optional provider, check store name, date, amount, and category before saving. A receipt is optional—you can always enter an expense manually.
